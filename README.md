🍔 Swiggy vs Zomato – Power BI Dashboard

📌 Project Overview

This project presents an interactive Power BI dashboard comparing Swiggy and Zomato to understand their business performance through data analysis and visualization.

🎯 Objectives

* Compare Swiggy and Zomato performance.
* Analyze sales and orders.
* Understand customer behaviour.
* Compare ratings and business performance.

🛠️ Tools & Technologies

* Microsoft Power BI
* Microsoft Excel
* Data Visualization
* Data Analytics

📊 Dashboard Highlights

* Sales Analysis
* Order Analysis
* Customer Behaviour
* Ratings Comparison
* Business Performance
